# Rhetoric Review · 修辞学大师

基于陈望道《修辞学发凡》完备体系的 Claude Code Skill，专为当代中文小说文本的修辞分析而生。

## 核心能力

- **四层修辞纠错**：素材层（概念代体验/二手经验/知识代感受/伪新鲜）+ 底子层（消极修辞四条件）+ 技法层（辞格误用/辞趣失调）+ 境界层/技法层非阻断瑕疵
- **硬伤即终止**：发现阻断性硬伤自动终止，只输出纠错报告，不在错误基础上做无意义的揭示
- **表达境界定位**：判断文本处于记述、表现还是糅合境界，理解修辞选择的语境
- **修辞现象扫描**：全面分析底子、辞格、辞趣的意味与音调
- **修辞与意图揭示**：揭示修辞选择服务意图方向的一致性、张力与偏离，展开可能性空间

## 核心理念

这个 skill **不做好坏评价**，只做两件事：这个技能**不作好坏评价**，只做两件事：

1. **纠错**：修辞存在客观硬伤——素材的体验基础缺失、消极修辞底子没打好、辞格用错
2. **揭示**：将修辞选择与意图之间的关系呈现出来，展开可能性的空间

### 三大核心信念

- **体验基础**：修辞素材来自观察、感受、经验和日常生活。缺失体验基础的修辞是硬伤
- **意图服务**：修辞选择的意义不能脱离意图方向来讨论
- **两大分野**：消极修辞（明白）与积极修辞（感染）不能混同，各有适用境界

## 理论基础

基于陈望道《修辞学发凡》的完备修辞学体系，包括：

- **消极修辞**：明确、通顺、平匀、稳密四条件
- **积极修辞**：材料上的辞格、意境上的辞格、词语上的辞格、章句上的辞格
- **辞趣**：辞的意味、辞的音调
- **修辞境界**：记述的境界、表现的境界、糅合的境界
